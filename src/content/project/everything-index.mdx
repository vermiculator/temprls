    - developing an end-to-end system for capture, storage, curation and fine-grained sharing of 'fragments' of data at arbitrary atomicity
    - designed for personal collections that are multi-modal and multi-purpose, working with an individual's everyday digital information needs, for knowledge-work, hobbies and life design
    - building a strong base for personal text, images, links, etc that is both private and shareable, portable, interfaceable, properly synced, etc 
    - prototyping interfaces that highlight personally defined connections between fragments, backed by semantic linking

    - imagine, for example
      * self-hosted Pinterest as file explorer, bookmarks, or open tabs
      * reference manager and note-taking tool
    - tech currently building on or considering
      * AnyType
      * Linkwarden
      * ActivityPods

    might seem vague or over-ambitious, but i'm essentially integrating others' projects and building interfaces / data structures over them, tying together similar needs across several use cases. the hardest jobs of ensuring desirable properties of the system (such as fine-grained data access and robust syncing) is therefore handled by others dedicated to those projects. the theoretical impetus is extrapolated in my Masters thesis.
