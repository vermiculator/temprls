# rls

This is a portfolio/personal site

## built with 
- [`@tinacms/astro`](https://www.npmjs.com/package/@tinacms/astro)
- [TinaCMS](https://tina.io/) ([docs](https://tina.io/docs))
- AstroJS ([docs](https://docs.astro.build))
- Tailwind CSS v4
- [`astro-icon`](https://github.com/natemoo-re/astro-icon)


## how to

Install dependencies:

```sh
pnpm install
```

Start the dev server

```sh
pnpm dev
```

Edit visually at `localhost:4321/admin/`:
